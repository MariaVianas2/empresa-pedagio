# Sistema de Pedágio em Java

Projeto desenvolvido para aplicar conceitos de Programação Orientada a Objetos na prática.

## Sobre o projeto
O sistema simula o funcionamento de uma concessionária de pedágio, permitindo o controle de praças, guaritas e tarifas, além do cálculo do total arrecadado.

## Tecnologias utilizadas
- Java
- Programação Orientada a Objetos
- Java Swing
- Estruturas de dados (Set / HashSet)

## Conceitos aplicados
- Encapsulamento
- Herança
- Polimorfismo
- Organização em camadas
- Relacionamento entre classes

## Aprendizados
Durante o desenvolvimento, foram identificados e corrigidos problemas como NullPointerException ao trabalhar com coleções não inicializadas, reforçando a importância da correta instanciação de objetos.

## Como executar
1. Abra o projeto em uma IDE Java, como IntelliJ IDEA
2. Execute a classe `Main`
